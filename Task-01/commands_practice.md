# 🎯 Task 01: Git Commands Practice Log

## My Git Commands Journey at Infrix

### ✅ Commands I've Practiced

| Command | What it does | When I used it |
|---------|-------------|----------------|
| `git init` | Creates a new repository | When starting my internship repo |
| `git clone <url>` | Copies a remote repo | To get the repository on my computer |
| `git status` | Shows what's changed | Before every commit to check my work |
| `git add <file>` | Stages changes | When I finished editing a file |
| `git commit -m "msg"` | Saves changes | Every time I completed a feature |
| `git log` | Shows history | To see my progress timeline |
| `git branch` | Lists branches | To check where I am |
| `git checkout -b <name>` | Creates new branch | When trying experimental features |
